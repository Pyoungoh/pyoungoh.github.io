# 복약 기록과 복용률

[약당번 메인으로 돌아가기](/pillkeep/)

이번 주와 이번 달의 복용률을 확인하고, 날짜별 복약 기록을 살펴보세요.

내가 얼마나 꾸준히 약을 챙기고 있는지 한눈에 볼 수 있습니다.

## 할 수 있는 것

- 이번 주, 이번 달 복용률 확인
- 예정, 완료, 건너뛰기, 미확인 횟수 확인
- 달력에서 날짜별 복약 현황 보기
- 날짜를 선택해 해당 날의 상세 기록 확인
- 앱을 열지 않은 날의 예정 복용도 "미확인"으로 집계

## 언제 사용하나요

이럴 때 활용해 보세요:

- 복약을 얼마나 꾸준히 하고 있는지 확인하고 싶을 때
- 어느 날 약을 먹었는지 되돌아보고 싶을 때
- 진료 때 복약 상황을 떠올려야 할 때

## 예시

복용률은 완료 ÷ (완료 + 건너뛰기 + 미확인)으로 계산하며, 아직 오지 않은 복용 시간은 계산에서 제외합니다.

## 앱 다운로드

약당번 앱은 곧 출시됩니다. 복약 알림, 오늘 복약 체크, 복약 기록을 한 앱에서 사용할 수 있습니다.
